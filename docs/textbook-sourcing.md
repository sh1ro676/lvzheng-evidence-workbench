## 4. 摘录规范

一张卡 = 一条法条 × 一本教材 × 一个观点。

| 字段 | 要求 |
|---|---|
| card_id | `法-条号-序号`，如 `MB-0022-01` |
| law | 必须用六部法全称 |
| article | 阿拉伯数字；「之一」写作 `N-1` |
| textbook / author / school | 与版权页一致 |
| edition / publisher / year | 与版权页一致 |
| chapter / section | 教材原章节名 |
| **page** | **必填**，形如 `P123`；无页码的摘录不可核验，一律拒收 |
| thesis | **自己的概括**，≤120 字，不得抄原文 |
| quote | **逐字摘录**，≤300 字，不得改写、不得拼接不同段落 |
| verified_by / verified_at | 核对人、核对日期 |

硬约束（校验器会拦）：

- `page` 或 `thesis` 为空 → 拒收；
- `quote` 超过 300 字 → 拒收；
- `thesis` 里整段包含 `quote` → 拒收（说明没做概括）；
- `law` 不在六部法清单 → 拒收。

版权边界：单条摘录 ≤300 字、全库累计不超过原书 10%，对外只展示摘录 + 出处，不提供原文下载。

## 5. 工作流

```
读书（有章在线阅读）
  ↓
按表填写 data/textbook_cards.csv（page 必填）
  ↓
python textbook_cards.py data/textbook_cards.csv   # 校验
  ↓
入库 → 按条文检索 → 生成讲解
```

校验不通过就不入库。宁可少一张卡，不要一张无法核验的卡。

## 6. 进度估算

- 单条摘录 + 核对：约 8–10 分钟；
- 一人一天：30–50 条；
- 六部法核心条文（讲解高频）约 600–800 条，全职约 1 个月，兼职 2–3 个月；
- 建议先做民法典总则编 1–204 条，跑通流程再扩。
